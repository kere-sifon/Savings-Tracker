# Household Finance Hub

A Next.js web app for managing household money in one place. After signing in, you land on a hub where you can open **Savings Tracker** or the **Kids** module.

**Savings Tracker** helps you record monthly savings entries, see contributions and balances, split money across accounts, and track lines of credit, with dashboards and charts for the overall picture.

**Kids** is a separate area for children’s finances: transactions, income and expenses by category, summaries, and simple reporting visuals.

The app uses authentication so only your household can access the data.
